## 9. Accessing the SciChartSurface inside SciFinanceChart

- [ ] Document how to reach and change the SciChart surfaces a `SciFinanceChart` draws on, with SciChart's own APIs. Example: a **watermark** (e.g. a `TextAnnotation` or `NativeTextAnnotation` with the symbol and interval, behind the candles) added with SciChart's Annotations API.
  - **Getting a surface:** `financeApi.getDefaultSurface()` (the price pane), `financeApi.chartPanes` (`Map<PaneId, ChartPane>`, each with `surface`), `financeApi.getPaneId(surface)`, and `paneGroupApi.getChart(id)`.
  - **When:** surfaces exist after `create` resolves (React: `onInit`). Panes added later (a new study) fire `paneSurfaceReady`, then `paneConfigured`: subscribe to add to those too. `surfaceConfig` runs as each surface is created.
  - **What's safe to change:** annotations, modifiers, axis options, background, `invalidateElement`. What the chart owns and may overwrite or fight: the X axis visible range (periods, live tip), `autoRange`, the theme's colours on `setTheme`, series added by studies, and keeping the user's own annotations apart from drawings (`drawingTypeNames`, saved by `toJSON`).
  - **Cleanup:** what to remove before `cleanup()`, and that a restored chart (`fromJSON`) needs the additions made again.
  - Already shown piecemeal: Keyboard and Touch adds modifiers to every pane (`chartPanes` + `paneConfigured`); Styling the Chart has `surfaceConfig`; Finance Chart API lists `getDefaultSurface`, `chartPanes`, `paneSurfaceReady`, `paneConfigured`. A page pulls these together and links to SciChart's own docs (annotations, modifiers, axes).
  - Where: a page under SciFinanceChart, e.g. `sci-finance-chart/accessing-the-scichart-surface/`, with live TS and React examples (watermark; maybe a custom modifier or a horizontal line annotation on the price pane).
