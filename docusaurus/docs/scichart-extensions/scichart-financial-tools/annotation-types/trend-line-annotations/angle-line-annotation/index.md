# AngleLineAnnotation

[AngleLineAnnotation:blue_book:](https://www.scichart.com/documentation/js/v5/typedoc-fin-tools/classes/anglelineannotation.html) draws a two-point angled guide line. It is a simple directional annotation for highlighting slope or projection.

It inherits the shared multi-point editing and label behavior from `scichart-financial-tools`.
