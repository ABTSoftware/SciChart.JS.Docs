# FibonacciTimeZoneAnnotation

[FibonacciTimeZoneAnnotation:blue_book:](https://www.scichart.com/documentation/js/v5/typedoc-fin-tools/classes/fibonaccitimezoneannotation.html) projects Fibonacci time zones from two points. It is used to mark potential time-based turning points.

It inherits the shared multi-point editing and label behavior from `scichart-financial-tools`.
