# Chart Types Guide

Which chart should you use, and how do you read it? Each guide explains one chart type in plain language: what it shows, when to use it, and how to read it. Each one comes with a live, interactive example and the code to build it in **JavaScript, React or Angular** with SciChart.js.

## Financial charts

| Chart | What it shows |
| --- | --- |
| [Candlestick chart](/learn/candlestick-chart/) | Open, high, low and close prices per period, with colour showing whether the price rose or fell |
