# Machine Learning

Each guide here explains one machine learning idea with a live chart you can change in your browser: the model trains or recomputes as you move a slider, so you can see what it does rather than read about it. Each one ends with the code to chart it in JavaScript, React or Angular with SciChart.js.

| Guide | What it covers |
| --- | --- |
| [Activation functions](/learn/machine-learning/activation-functions/) | Sigmoid, tanh, ReLU, GELU and softmax: formulas, derivatives and a network trained live |
| [Anomaly detection](/learn/machine-learning/anomaly-detection/) | Z-scores, seasonal baselines and isolation forests on a live sensor stream |
| [Decision boundary](/learn/machine-learning/decision-boundary/) | How k-NN, logistic regression, trees, forests, naive Bayes and SVMs divide data, trained live |
| [Dimensionality reduction](/learn/machine-learning/dimensionality-reduction/) | PCA, t-SNE and UMAP compared, with a 2D and 3D embedding of digit images |
| [Hierarchical clustering](/learn/machine-learning/hierarchical-clustering/) | How to read a dendrogram, linkage methods, and DBSCAN |
| [K-means clustering](/learn/machine-learning/k-means-clustering/) | How k-means works, the elbow method and silhouette score, step by step |
| [Regularization](/learn/machine-learning/regularization/) | Ridge and lasso regression, overfitting and the bias–variance trade-off |
| [ROC curve](/learn/machine-learning/roc-curve/) | How ROC and precision-recall curves are built, what AUC means, and choosing a threshold |
| [Support vector machine](/learn/machine-learning/support-vector-machine/) | Margins, support vectors and the kernel trick, in 2D and 3D |

For the statistics charts these guides use, see [correlation matrix](/learn/chart-types/cartesian/correlation-matrix/) and [residual plot and Q-Q plot](/learn/chart-types/cartesian/residual-plot/).
