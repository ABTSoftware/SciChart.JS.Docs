# CLAUDE.md: learning center pages (`docs/learn/`)

The rules for writing and changing learn pages are kept in SciChart's private `Marketing` repo, in `learning-center/CLAUDE.md`. **Read that file before doing any work in this folder, and follow it.**

1. Look for the `Marketing` repo next to this one, at `../Marketing` from this repo's root (for example `~/Documents/GitHub/Marketing`). If you find it, run `git -C <path> pull` and read `learning-center/CLAUDE.md`, then `learning-center/README.md`.
2. **If it isn't on disk, stop and tell the user:** "The learn page rules are in the private SciChart Marketing repo. Please clone `https://github.com/SciChartOrg/Marketing` next to SciChart.JS.Docs (access is for SciChart management and marketing), then ask me again." Don't write or restructure learn pages without those rules.

**This repo is public.** Never copy anything from the Marketing repo into it: no rules, notes, research, data or scripts, and nothing about them in commit messages, PR descriptions or code comments.

This file is excluded from the build (`exclude` in `docusaurus.config.ts`), so it is never published.
