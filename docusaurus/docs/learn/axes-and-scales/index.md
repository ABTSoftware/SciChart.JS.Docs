# Axes and Scales

The axes of a chart decide how its values are mapped to positions, and so what the shapes on the chart mean. Each guide here explains one kind of axis or scale in plain language: how it works, how to read it and when to use it, with a live, interactive example and the code to build it in **JavaScript, React or Angular** with SciChart.js.

| Topic | What it shows |
| --- | --- |
| [Cartesian graph](/learn/axes-and-scales/cartesian-graph/) | The x-y grid behind almost every chart: the x and y axes, the origin, ordered pairs (x, y), the four quadrants and scale, and how it compares with polar coordinates |
| [Log scale graph](/learn/axes-and-scales/log-scale-graph/) | Data on a logarithmic axis, where each step multiplies the value (1, 10, 100, 1,000), so values across many orders of magnitude fit on one chart and steady percentage growth is a straight line |
| [XYZ graph (3D axes)](/learn/axes-and-scales/xyz-graph/) | The x, y and z axes of a 3D chart: which axis is up, right- vs left-handed axes, how to read a point's (x, y, z) and perspective vs orthographic views |

For the chart types themselves, see [types of charts and graphs](/learn/chart-types/).
