# Applications

Each guide here covers one application, from medicine and life sciences to engineering, energy, defence, the oceans, the weather, motorsport, astronomy, signal processing, machine learning and business. It explains how that field records its data, how people read the charts that come out of it, and how to build the same view with a live example you can change in your browser and the code to chart it in JavaScript, React or Angular with SciChart.js.

The guides are grouped by sector, in alphabetical order.
