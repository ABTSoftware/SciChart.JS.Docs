# Technical Indicators Reference

Each page below explains one technical indicator: what it is, how it is calculated, how traders read it, and how to add it to a JavaScript or React financial chart with SciTrader.js, with live TypeScript and React examples you can edit in CodePen.

| Indicator | Kind | Draws on | SciTrader study |
| --- | --- | --- | --- |
| [RSI (Relative Strength Index)](/financial-charts/studies-and-indicators/indicators/rsi-relative-strength-index/) | Momentum oscillator, 0 to 100 | Its own pane | `RSIStudy` |
| [MACD (Moving Average Convergence/Divergence)](/financial-charts/studies-and-indicators/indicators/macd/) | Trend and momentum oscillator | Its own pane | `MACDStudy` |
| [Bollinger Bands](/financial-charts/studies-and-indicators/indicators/bollinger-bands/) | Volatility bands | The price pane | `BollingerBandsStudy` |
| [Moving Averages (SMA, EMA, WMA)](/financial-charts/studies-and-indicators/indicators/moving-averages-sma-ema-wma/) | Trend lines | The price pane | `SMAStudy`, `EMAStudy`, `WMAStudy` |

For every indicator SciTrader has, with its options and defaults, see [Technical Indicators and Studies](/financial-charts/studies-and-indicators/#the-catalogue). To add indicators at runtime or build an indicator picker, see [Add Technical Indicators to a Financial Chart](/financial-charts/studies-and-indicators/add-indicators/).
