# Github Source Code Access

:::info
To access the source-code for scichart.js, you will need a source-code enabled product. Products purchased from our store that enable SciChart.js source-code access include:

- SciChart Bundle 2D/3D Source (product code `SC-BUNDLE-SDK-ENTERPRISE`)

For purchasing, please visit [scichart.com/shop](https://www.scichart.com/shop). For pre-sales enquiries [contact technical sales](https://www.scichart.com/contact-us/#pre-sales) and for licensing support post-sales please contact [technical support](https://www.scichart.com/contact-us/#tech-support).
:::

If you are a SciChart.js Source-Code customer, you can now access the source code via our [Github repository](https://www.scichart.com/github-repository-for-scichart-source-code-customers/).
To get access, please follow the steps below:

## Step 1: Activate your developer license

You will need to activate a developer license for product code `SC-BUNDLE-SDK-ENTERPRISE` following the steps from [activating a paid developer license](/user-manual/licensing-scichart-js/activating-paid-licenses)

## Step 2: Link your github account

You can now link your github account in the [scichart.com/my-account](https://www.scichart.com/my-account) page.

1. Navigate to **My Account** - **Orders & Keys** - **Manage Licenses** for the source-code product you have purchased
2. Under the **"License Details"** section, click the link **"Update your Github Account"**
3. Submit a Github username, accept the terms and click submit

![Link Github account to scichart source code order](/images/licensingtroubleshooting_github.png)

![Link Github account to scichart source code order](/images/licensingtroubleshooting_github3.png)

4. You will receive an invite email **to the email associated with your Github account**. Click to accept this to be granted access to the repository.

5. You should now be able to access the SciChart.js private Github repository at [github.com/ABTSoftware/SciChartJS](https://github.com/ABTSoftware/SciChartJS)

![View SciChart.js private github repo with source code](/images/licensingtroubleshooting_github2.png)

:::info
The option to link your github account will only be available if you have a support-active, **activated source-code license** type (SciChart Bundle 2D/3D Source)
:::
:::warning
If your support subscription expires and is not renewed, access to the github repos with SciChart source-code will be removed
:::
